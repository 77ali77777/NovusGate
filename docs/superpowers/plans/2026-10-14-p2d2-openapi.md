# P2d-2 OpenAPI Document and `/api` JSON Fallbacks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- Publish an OpenAPI 3.0 document of the whole REST API that cannot drift from the code. It is built from the Go types, every registered route must appear in it, and every contract-test response must validate against it.
- Unknown `/api` paths and wrong methods answer in the unified JSON error format.
- The iptables-import refusal gets its own error code before codes are released.

**Architecture:**
- `openapi.go` holds one table of documented operations (method, path, summary, tag, request/response Go types and status). A small reflection-based schema generator turns the Go types (`models.Network`, `models.Node`, `FirewallStatus`, …) into components.
- `GET /api/v1/openapi.json` serves the document, and a golden copy in `testdata/openapi.json` shows every change in review.
- A route-coverage test walks the mux router. A tiny schema validator checks every `TestContract` response against the operation's schema.

**Tech Stack:** Go 1.23 standard library (`reflect`, `encoding/json`), gorilla/mux (`Walk`, `Match`), PostgreSQL 16 (tests).

**Spec:**
- `docs/superpowers/specs/2026-10-13-p2-backend-core-design.md` §1 (P2d row: "OpenAPI 3 sənədi kontrakt snapshot-larından") and §5 (P2d-2: OpenAPI plus a route coverage test).
- Master spec `docs/superpowers/specs/2026-10-13-novusgate-rebuild-design.md` §5: P5 depends on "P2 (OpenAPI)".
- P2d-1 final review deferred minors #2 (the docs promised JSON errors for every path, but unknown `/api` paths fall to the SPA) and #3 (iptables import returns a generic `conflict`).

## Global Constraints

- **No new Go modules and no npm packages.** `openapi-typescript` is P5's approved package, not this plan's.
- **The document is OpenAPI 3.0.3 JSON.**
  - Nullable is expressed as `"nullable": true`.
  - A nullable `$ref` is wrapped in `allOf`.
  - A Go `nil` slice or map encodes as JSON `null`, so slices and maps are nullable.
- **Request bodies:**
  - Named Go request types (`OpenPortRequest`, `v2ServiceRequest`, …) get real schemas.
  - Handler-local anonymous request structs are documented as `{"type":"object"}` with a description listing the fields. Turning them into named DTOs is P2d-3 (service layer); do not refactor handlers here.
- **API behaviour changes in this plan:**
  - `GET /api/v1/openapi.json` (new);
  - an unknown `/api/…` path → `404 not_found` (today: the SPA's index or a plain-text 404);
  - a known `/api` path with a wrong method → `405 method_not_allowed` with an `Allow` header (today: the SPA);
  - iptables import in nft mode → code `firewall_engine_enforcing` (status stays 409).

  Nothing else changes; contract snapshots prove it.
- **Environment:** Go runs only in Docker (`bash server/scripts/test-with-postgres.sh`). Golden updates go through `bash server/scripts/update-contracts.sh` (it runs `-run 'TestContract'`, so new golden tests are named `TestContract…`). The WSL shim expands `$`/`|`, so logic goes in script files.
- Commits carry no `Co-Authored-By`/"Claude"/"Anthropic"/"AI generated" lines. Comments in English, docs in Azerbaijani with full diacritics.

## Review Focus

1. **A route added later without documentation.**
   - Expected: CI fails, naming the method and path.
   - Pinned by Task 2 `TestEveryRouteIsDocumented`.
2. **A response field renamed or retyped in a model** (e.g. `Node.VirtualIP`).
   - Expected: the golden `testdata/openapi.json` diff shows it, and contract responses fail validation if the doc and the reality disagree.
   - Pinned by Task 2 `TestContractOpenAPI` and Task 3 `TestContract` + `assertMatchesSpec`.
3. **`null` collections** (`endpoints: null` on nodes, nil maps).
   - Expected: they validate. The document must describe the wire as it is, not as we wish it were.
   - Pinned by Task 3 through the `node_get` contract case.
4. **The `/api` fallback must not swallow real routes or the SPA.**
   - Expected: `/` and `/index.html` still reach the SPA; `/health` and `/api/v1/auth/login` still work.
   - Pinned by Task 1 `TestAPIFallbacks`.
5. **Unauthenticated access to the document.**
   - Expected: it is behind the same Bearer auth as the rest of `/api/v1` (it lists every endpoint).
   - Pinned by Task 2 `TestOpenAPIIsServedBehindAuth`.

`api_fallback.go`:

```go
package rest

import (
	"net/http"
	"strings"

	"github.com/gorilla/mux"
)

// fallbackMethods are tried to tell "wrong method" (405) from "no such
// path" (404) for an /api request no route matched.
var fallbackMethods = []string{"GET", "POST", "PUT", "PATCH", "DELETE"}

// handleAPIFallback answers /api requests that matched no route in the
// unified error format instead of falling through to the SPA.
func (s *Server) handleAPIFallback(w http.ResponseWriter, r *http.Request) {
	var allowed []string
	for _, m := range fallbackMethods {
		if m == r.Method {
			continue
		}
		probe := r.Clone(r.Context())
		probe.Method = m
		var match mux.RouteMatch
		if s.router.Match(probe, &match) && match.Route != nil {
			if name := match.Route.GetName(); name != "api-fallback" && name != "spa" {
				allowed = append(allowed, m)
			}
		}
	}
	if len(allowed) > 0 {
		w.Header().Set("Allow", strings.Join(allowed, ", "))
		errorResponse(w, http.StatusMethodNotAllowed, "method "+r.Method+" is not allowed for "+r.URL.Path)
		return
	}
	errorResponse(w, http.StatusNotFound, "no API endpoint at "+r.URL.Path)
}
```

In `setupRoutes`, replace `s.router.PathPrefix("/").HandlerFunc(s.handleSPA)` with:

// TestEveryRouteIsDocumented fails when a route is registered without a
// docOps entry, or documented without being registered.
func TestEveryRouteIsDocumented(t *testing.T) {
	s, _, _ := newContractServer(t)
	registered := map[string]bool{}
	err := s.router.Walk(func(route *mux.Route, _ *mux.Router, _ []*mux.Route) error {
		tpl, err := route.GetPathTemplate()
		if err != nil {
			return nil
		}
		methods, err := route.GetMethods()
		if err != nil {
			return nil // catch-alls (api-fallback, spa) and the /api/v1 subrouter itself
		}
		for _, m := range methods {
			if m != "OPTIONS" {
				registered[m+" "+tpl] = true
			}
		}
		return nil
	})
	if err != nil {
		t.Fatal(err)
	}
	documented := map[string]bool{}
	for _, op := range docOps {
		documented[op.Method+" "+op.Path] = true
	}
	var missing, stale []string
	for k := range registered {
		if !documented[k] {
			missing = append(missing, k)
		}
	}
	for k := range documented {
		if !registered[k] {
			stale = append(stale, k)
		}
	}
	sort.Strings(missing)
	sort.Strings(stale)
	if len(missing) > 0 || len(stale) > 0 {
		t.Fatalf("undocumented routes:\n%s\ndocumented but not registered:\n%s", strings.Join(missing, "\n"), strings.Join(stale, "\n"))
	}
}

		t.Errorf("Node schema: virtual_ip=%v expires_at=%v", node["virtual_ip"], node["expires_at"])
	}
}

var (
	timeType = reflect.TypeOf(time.Time{})
	ipType   = reflect.TypeOf(net.IP{})
	pathVar  = regexp.MustCompile(`\{([^}]+)\}`)
)

// schemaGen turns Go types into OpenAPI 3.0 schemas; named structs become
// components referenced by $ref.
type schemaGen struct{ components map[string]any }

func (g *schemaGen) schema(v any) map[string]any {
	if _, ok := v.(freeform); ok {
		return map[string]any{"type": "object"}
	}
	return g.typeSchema(reflect.TypeOf(v))
}

func nullable(s map[string]any) map[string]any {
	if _, isRef := s["$ref"]; isRef {
		return map[string]any{"allOf": []any{s}, "nullable": true}
	}
	s["nullable"] = true
	return s
}

func (g *schemaGen) typeSchema(t reflect.Type) map[string]any {
	switch t {
	case timeType:
		return map[string]any{"type": "string", "format": "date-time"}
	case ipType:
		return map[string]any{"type": "string", "description": "IP address"}
	}
	switch t.Kind() {
	case reflect.Ptr:
		return nullable(g.typeSchema(t.Elem()))
	case reflect.Slice, reflect.Array:
		return nullable(map[string]any{"type": "array", "items": g.typeSchema(t.Elem())}) // a nil slice encodes as null
	case reflect.Map:
		return nullable(map[string]any{"type": "object", "additionalProperties": g.typeSchema(t.Elem())})
	case reflect.String:
		return map[string]any{"type": "string"}
	case reflect.Bool:
		return map[string]any{"type": "boolean"}
	case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64,
		reflect.Uint, reflect.Uint8, reflect.Uint16, reflect.Uint32, reflect.Uint64:
		return map[string]any{"type": "integer"}
	case reflect.Float32, reflect.Float64:
		return map[string]any{"type": "number"}
	case reflect.Struct:
		name := t.Name()
		if name == "" {
			return g.structSchema(t)
		}
		if _, ok := g.components[name]; !ok {
			g.components[name] = map[string]any{} // break recursion
			g.components[name] = g.structSchema(t)
		}
		return map[string]any{"$ref": "#/components/schemas/" + name}
	}
	return map[string]any{} // interface{}: any value
}

func (g *schemaGen) structSchema(t reflect.Type) map[string]any {
	props := map[string]any{}
	var required []string
	for i := 0; i < t.NumField(); i++ {
		f := t.Field(i)
		if !f.IsExported() {
			continue
		}
		name, opts, _ := strings.Cut(f.Tag.Get("json"), ",")
		if name == "-" {
			continue
		}
		if name == "" {
			name = f.Name
		}
		props[name] = g.typeSchema(f.Type)
		if !strings.Contains(opts, "omitempty") {
			required = append(required, name)
		}
	}
	s := map[string]any{"type": "object", "properties": props}
	if len(required) > 0 {
		sort.Strings(required)
		s["required"] = required
	}
	return s
}

// openAPIDocument builds the OpenAPI 3.0.3 document from docOps.
func openAPIDocument() map[string]any {
	g := &schemaGen{components: map[string]any{
		"Error": map[string]any{
			"type":     "object",
			"required": []string{"error"},
			"properties": map[string]any{"error": map[string]any{
				"type":     "object",
				"required": []string{"code", "message"},
				"properties": map[string]any{
					"code":    map[string]any{"type": "string", "description": "stable snake_case code, see docs/api.md"},
					"message": map[string]any{"type": "string"},
				},
			}},
		},
	}}
	errorRef := map[string]any{"description": "Error", "content": map[string]any{
		"application/json": map[string]any{"schema": map[string]any{"$ref": "#/components/schemas/Error"}}}}
	paths := map[string]any{}
	for _, op := range docOps {
		item, _ := paths[op.Path].(map[string]any)
		if item == nil {
			item = map[string]any{}
			paths[op.Path] = item
		}
		resp := map[string]any{"description": http.StatusText(op.Status)}
		switch body := op.Response.(type) {
		case nil:
		case mediaType:
			resp["content"] = map[string]any{string(body): map[string]any{"schema": map[string]any{"type": "string"}}}
		default:
			resp["content"] = map[string]any{"application/json": map[string]any{"schema": g.schema(body)}}
		}
		o := map[string]any{
			"summary":     op.Summary,
			"tags":        []string{op.Tag},
			"operationId": strings.ToLower(op.Method) + pathVar.ReplaceAllString(strings.NewReplacer("/api/v1", "", "/", "_", "-", "_", ".", "_").Replace(op.Path), "by_$1"),
			"responses":   map[string]any{strconv.Itoa(op.Status): resp, "default": errorRef},
		}
		var params []any
		for _, m := range pathVar.FindAllStringSubmatch(op.Path, -1) {
			params = append(params, map[string]any{"name": m[1], "in": "path", "required": true, "schema": map[string]any{"type": "string"}})
		}
		if params != nil {
			o["parameters"] = params
		}
		if op.Request != nil {
			o["requestBody"] = map[string]any{"required": true, "content": map[string]any{
				"application/json": map[string]any{"schema": g.schema(op.Request)}}}
		}
		if op.Public {
			o["security"] = []any{}
		}
		item[strings.ToLower(op.Method)] = o
	}
	return map[string]any{
		"openapi": "3.0.3",
		"info":    map[string]any{"title": "NovusGate Control Plane API", "version": "0.1.0"},
		"servers": []any{map[string]any{"url": "/"}},
		"security": []any{map[string]any{"bearer": []any{}}},
		"components": map[string]any{
			"schemas":         g.components,
			"securitySchemes": map[string]any{"bearer": map[string]any{"type": "http", "scheme": "bearer"}},
		},
		"paths": paths,
	}
}

// handleOpenAPI serves the document (behind the same auth as the API).
func (s *Server) handleOpenAPI(w http.ResponseWriter, r *http.Request) {
	jsonResponse(w, http.StatusOK, openAPIDocument())
}

// validateSchema checks a decoded JSON value against the subset of OpenAPI
// 3.0 the generator emits: type, properties, required, items,
// additionalProperties, nullable, $ref and a single-element allOf.
func validateSchema(schema map[string]any, v any, schemas map[string]any, at string) []string {
	if ref, ok := schema["$ref"].(string); ok {
		return validateSchema(schemas[strings.TrimPrefix(ref, "#/components/schemas/")].(map[string]any), v, schemas, at)
	}
	if all, ok := schema["allOf"].([]any); ok && len(all) == 1 {
		if v == nil && schema["nullable"] == true {
			return nil
		}
		return validateSchema(all[0].(map[string]any), v, schemas, at)
	}
	if v == nil {
		if schema["nullable"] == true || len(schema) == 0 {
			return nil
		}
		return []string{at + ": null is not allowed"}
	}

	switch schema["type"] {
	case "object":
		obj, ok := v.(map[string]any)

			return []string{at + ": want object"}

				}
			}
		}

			if ps, ok := props[k].(map[string]any); ok {

			} else if ap, ok := schema["additionalProperties"].(map[string]any); ok {

// assertMatchesSpec finds the documented operation for the request and
// checks the response's status and JSON body against it.
func assertMatchesSpec(t *testing.T, s *Server, method, path string, rec *httptest.ResponseRecorder) {
	t.Helper()
	var match mux.RouteMatch
	if !s.router.Match(httptest.NewRequest(method, path, nil), &match) || match.Route == nil {
		t.Errorf("%s %s: no route", method, path)
		return
	}
	tpl, _ := match.Route.GetPathTemplate()
	if name := match.Route.GetName(); name == "api-fallback" || name == "spa" {
		tpl = "" // only the error body is checked below
	}
	doc := openAPIDocument()
	schemas := doc["components"].(map[string]any)["schemas"].(map[string]any)
	var body any
	isJSON := strings.HasPrefix(rec.Header().Get("Content-Type"), "application/json")
	if isJSON && rec.Body.Len() > 0 {
		if err := json.Unmarshal(rec.Body.Bytes(), &body); err != nil {
			t.Errorf("%s %s: invalid JSON: %v", method, path, err)
			return
		}
	}
	if rec.Code >= 400 {
		if errs := validateSchema(map[string]any{"$ref": "#/components/schemas/Error"}, body, schemas, "body"); len(errs) > 0 {
			t.Errorf("%s %s %d: error body does not match Error: %v", method, path, rec.Code, errs)
		}
		return
	}
	for _, op := range docOps {
		if op.Method != method || op.Path != tpl {
			continue
		}
		if op.Status != rec.Code {
			t.Errorf("%s %s: status %d, documented %d", method, tpl, rec.Code, op.Status)
			return
		}
		switch op.Response.(type) {
		case nil, mediaType:
			return
		}
		g := &schemaGen{components: map[string]any{}}
		schema := g.schema(op.Response)
		for k, v := range g.components {
			schemas[k] = v
		}
		if errs := validateSchema(schema, body, schemas, "body"); len(errs) > 0 {
			t.Errorf("%s %s: response does not match the documented schema:\n%s", method, tpl, strings.Join(errs, "\n"))
		}
		return
	}
	t.Errorf("%s %s: undocumented operation", method, tpl)
}
