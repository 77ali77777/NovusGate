User requirement (2026-10-15, "unutma"): in every section of the panel (and Center), every input/setting gets a "?" help marker. Clicking or hovering it explains three things: what the field is, who needs it and why, and what happens when it is set or changed (including risks).

**Why:** the user wants the panel understandable without outside docs; operators should not have to guess what a field does.
**How to apply:** any new or changed input ships with its help text (en + az i18n, same as all UI text, see [[novusgate-rebuild-roadmap]]); reviews should flag an input without one.
